# Task 11 - React To-Do List Application

A responsive React to-do list application built with functional components and the `useState` hook. It covers the required task operations and includes bonus local storage, editing, and filtering.

## Features

- Add new tasks with empty-input validation
- Display all tasks in a styled list
- Mark tasks as completed with a strikethrough visual state
- Delete tasks instantly
- Edit and update existing tasks
- Filter tasks by all, pending, and completed
- Save tasks in local storage after refresh
- Responsive UI for mobile and desktop

## Tech Stack

- React.js
- Vite
- CSS

## Setup

```bash
cd Task11-TodoApp
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Vercel Deployment

Recommended from the repository root:

- Root directory: repository root
- Build command: `npm run build`
- Output directory: `dist`

This serves the main hub at `/` and this app at `/Task11-TodoApp/`.
